Generated by `rust-gate describe`; `just docs` rewrites this file and a test refuses a stale copy. Every step, what it reads, runs and writes, from the declaration the gate enforces while the step runs: an input, a tool or a report the step did not declare is refused. The runner's own files and the job's directories are read by every step and not listed.
